Discky GitHub

Your Mac is full of things nobody remembers creating.

AI models apps downloaded behind your back, build folders coding agents left in every project, caches of tools you used once. Discky finds them, says what each one is and whether it is safe to remove, and removes it only through the tool that owns it. Nothing is ever deleted with a bare rm.

Install

Apple Silicon, macOS 15 or later. Free and open source (MIT).

Homebrew
brew install --cask AlxGolubev/discky/discky
Download
Installer package.pkg App bundle.zip latest release
Agent
claude mcp add discky -- /opt/homebrew/bin/discky-mcp

The app is not notarized (there is no paid Apple account behind it). The cask clears the quarantine flag for you; for the package, allow it once in System Settings → Privacy & Security → Open Anyway, or run sudo installer -pkg Discky-<version>.pkg -target /. Grant Full Disk Access on first launch so the scan can see all of ~/Library.

What it finds

  • Models from Ollama, Hugging Face, LM Studio, oMLX, MacWhisper.
  • Dev caches of Cargo, npm, pnpm, pip, uv, Go, Gradle, Xcode, Docker and more.
  • Project builds: target, node_modules, virtual environments, dist.
  • Applications with the files they left behind, and leftovers of apps already gone.
  • App caches, language versions from mise, and large & old files in your home folder.

Every size is bytes actually allocated on disk: sparse images, APFS clones, hard links and cloud-only iCloud files are counted honestly. The MCP server gives your agent the same scanner, findings and planner; deletion by an agent stays off until you turn it on. Read the full README →
